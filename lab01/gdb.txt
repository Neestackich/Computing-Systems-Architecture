1. run <arg1, arg2>/process launch -- <arg1, arg2> 
Аргументы к программе могут быть заданы как аргументы к команде run: r arg1 arg2 ...  или r < <имя_файла>. run без аргументов использует те же аргументы, которые использовались предыдущей командой run, или которые установлены командой set args. 
2. Команда b/br/break <номер строки>, b/br/break <имя_функции>, 
3. Команда n/next/thread step-over
4. Команда s/step/thread step-in
5. Команда c/continue
6. Команда po <имя_переменной, выражение>
7. Команда watchpoint set variable/wa s v <имя переменной>
8. Команда fr v/frame variable
9. Команда q/quit, ctrl+d
